# LAMDA Model Reuse

**Model Reuse Research Group · LAMDA · Nanjing University**

We explore how existing AI models can be effectively reused, selected, adapted, and routed to solve new tasks with improved efficiency, scalability, and accessibility.

Our research spans model reuse, large language model routing, efficient inference, and the evaluation of reusable AI systems.

## Research Interests

- **Model Reuse:** Model selection, adaptation, transferability, and composition.
- **LLM & Multimodal Routing:** Selecting appropriate models according to task requirements, capabilities, and resource constraints.
- **Efficient AI Systems:** Cost-aware decision-making, efficient inference, and resource optimization.
- **Benchmarking & Evaluation:** Reproducible benchmarks and evaluation frameworks for model reuse and routing.

## Open-Source Projects

| Project | Description |
|---|---|

| [SaveRouter](https://github.com/LAMDA-Model-Reuse/SaveRouter) | Sparse-supervision LLM routing with feedback acquisition and deployment considerations. |
| [MMR-Bench](https://github.com/LAMDA-Model-Reuse/MMR-Bench) | A benchmark for multimodal LLM routing. |
| [RouteJudge](https://github.com/LAMDA-Model-Reuse/RouteJudge) | A platform for preference-aware LLM routing evaluation. |
